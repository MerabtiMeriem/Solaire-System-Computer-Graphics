# Solar System Project

A Computer graphics project using C++ and OpenGL to developed a 3D solar system

## Technologies

- C++
- OpenGL
- FreeGLUT
- CMake

## Build and Run

```bash
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_MAKE_PROGRAM="C:/msys64/ucrt64/bin/mingw32-make.exe" -DCMAKE_CXX_COMPILER="C:/msys64/ucrt64/bin/g++.exe"

cmake --build build

./build/ComputerGraphics.exe
```
